# WorkOut

WorkOut est une application mobile développée avec React Native et le framework Expo.

L'interface a été conçue avec NativeWind (Tailwind CSS) et React Native Paper pour offrir une expérience utilisateur moderne et fluide.

## Fonctionnalités principales

- Outils pratiques pour les entraînements sportifs
- Chronomètre animé interactif
- Navigation fluide et intuitive
