# Jeu de Quizz

Pour un projet d'évaluation, j'ai conçu et développé une application de bureau de quiz en Python reposant sur la bibliothèque graphique **Tkinter**.

L'application a été pensée pour être entièrement modulable : l'utilisateur peut personnaliser l'apparence de l'interface et enrichir la banque de questions via un système de gestion de fichiers locaux.

## Fonctionnalités principales

- Interface graphique **Tkinter** personnalisable selon les préférences du joueur
- Système de stockage sur fichiers permettant d'ajouter ses propres questions
- Création et chargement de questionnaires personnalisés
