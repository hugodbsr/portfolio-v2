# Logiciel de classification

Dans le cadre d'un projet d'évaluation en équipe, nous avons conçu un logiciel permettant de charger, visualiser et classifier un jeu de données.

L'application détermine automatiquement la catégorie d'une nouvelle donnée à partir des données existantes grâce à l'implémentation de l'algorithme des _k_ plus proches voisins (**k-NN**), le tout structuré selon le patron d'architecture **MVC (Modèle-Vue-Contrôleur)**.

## Fonctionnalités principales

- Importation et visualisation graphique d'ensembles de données
- Classification automatique de nouvelles entrées via l'algorithme **k-NN**
- Architecture **MVC** modulaire garantissant l'indépendance des composants
