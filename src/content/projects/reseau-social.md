# Réseau Social

Dans le cadre d'un projet d'évaluation réalisé en binôme, nous avons développé une application web complète inspirée du fonctionnement d'un réseau social moderne.

L'application repose sur Apache Tomcat, un serveur d'applications open source permettant le déploiement d'applications web Java dynamiques avec une gestion robuste des connexions et des ressources.

## Fonctionnalités principales

- Création et gestion de comptes utilisateurs
- Envoi de messages privés et partage d'images entre utilisateurs
- Espaces de discussion en groupe
- Persistance des données relationnelles
