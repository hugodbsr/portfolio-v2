# Kahouf

Dans le cadre d'un projet d'évaluation, j'ai développé Kahouf, un jeu de quiz interactif conçu avec le moteur de jeu open source Godot.

Après avoir réalisé une première version de quiz en Python, j'ai choisi Godot afin d'offrir une interface plus dynamique et d'interfacer le jeu avec une API distante pour récupérer les questions en temps réel.

## Fonctionnalités principales

- Récupération dynamique des questions et réponses via des requêtes API
- Interface de jeu animée et interactive sous Godot Engine
- Calcul du score et enchaînement fluide des manches
