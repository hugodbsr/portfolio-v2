# XMLViewer

Dans le cadre d'un projet de traduction de jeu vidéo (Shin Megami Tensei IV), j'ai conçu et développé un logiciel de bureau en Java et JavaFX destiné aux traducteurs.

L'objectif était d'offrir une interface graphique intuitive permettant d'éditer des fichiers de dialogues XML complexes sans avoir à manipuler directement les balises techniques.

## Fonctionnalités principales

- Ouverture, lecture et sauvegarde sécurisée de fichiers XML de dialogues
- Interface d'édition visuelle pensée pour des utilisateurs non techniciens
- Prévisualisation et navigation rapide entre les entrées de texte
